# 浏览器会话

## 目标：$ARGUMENTS

使用 **bd-browser** 技能在此 URL 打开抓取浏览器会话。严格遵循技能说明。

导航后，拍摄快照以查看页面结构，然后询问用户下一步想执行什么交互（点击按钮、填写表单、滚动以加载更多内容等）。
